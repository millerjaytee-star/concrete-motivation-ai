# Mobile and PWA Release Status

No native iOS/Android project, Expo application, service worker, web app manifest, install icons, push-notification integration, or store metadata exists in this repository today. The public website is responsive, but it is not currently an installable PWA or a native mobile release.

Do not submit or advertise a mobile app until the existing approved member application is migrated into this repository, authenticated mobile journeys pass staging, privacy and account-deletion requirements are implemented, production assets are approved, and Apple/Google owner actions are documented and completed.

The web release must not be blocked merely because native packaging is a later milestone. Mobile release approval is a separate gate after the member application becomes repository-owned.
