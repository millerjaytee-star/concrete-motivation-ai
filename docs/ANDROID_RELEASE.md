# Android Release

Use the same canonical Lovable application, backend, roles, data, and entitlements as web/iOS. Do not create a disconnected Android product and do not derive it from the stale local Next.js app.

After importing canonical source, configure the approved application ID, Capacitor/native shell if selected, adaptive icon, splash, deep/app links, auth callbacks, version code/name, network/security policy, keyboard/back behavior, and signing template. Production keystore and passwords remain owner-controlled and uncommitted.

Build an Android App Bundle, test on common phone sizes, then use Play internal testing. Complete store listing, screenshots, short/full descriptions, category, privacy policy, Data Safety, content rating, reviewer/login instructions, and release notes. Complete closed testing if the account requires it. Jaytee approves production rollout.
