# App Store Asset Checklist

- [ ] Approved iOS 1024×1024 icon without transparency
- [ ] Android adaptive foreground/background and 512×512 store icon
- [ ] Branded splash screens and launch-safe wordmark
- [ ] Current iPhone screenshots for required display sizes
- [ ] Current Android phone screenshots
- [ ] Tablet/iPad screenshots if those devices are supported
- [ ] Google Play feature graphic
- [ ] App name, subtitle, promotional text, short description, full description, keywords, category
- [ ] Support URL, marketing URL, privacy URL, terms URL
- [ ] Age/content rating answers
- [ ] Apple App Privacy and Google Data Safety answers based on verified behavior
- [ ] Reviewer contact, test account, and instructions stored securely outside Git
- [ ] Version notes and build/version numbers
- [ ] Owner-approved authentic media rights; no invented claims or metrics
